Common Quick Fixes:

[ ] Something broken -> docker-compose down -v && docker-compose up

KEEPING THINGS RUNNING
=======================
STOPPING (when done):
[ ] Press Ctrl+C in PowerShell (where docker-compose up is running)
[ ] Wait for "Gracefully stopping..."
[ ] Data is saved between stops

STARTING AGAIN (next time):
[ ] Open PowerShell
[ ] cd to project folder
[ ] Run: docker-compose up
[ ] Wait 30 seconds
[ ] Website ready at http://localhost:8000

FULL RESET (delete all data):
[ ] Run: docker-compose down -v
[ ] Run: docker-compose up
[ ] Takes 3-5 minutes
[ ] Database empty, fresh start

USEFUL COMMANDS (run in new PowerShell while running)
=======================================================
docker-compose ps
  -> Shows running containers

docker-compose logs web
  -> Shows Django app logs

docker-compose logs postgres
  -> Shows database logs

docker-compose exec web python manage.py shell
  -> Opens Python shell with Django

docker-compose exec web python manage.py test
  -> Runs all tests

docker-compose down
  -> Stops everything (data preserved)

docker-compose down -v
  -> Stops everything AND deletes database
